# No Token Policy

## Policy statement

CeloHT does not issue, operate, or sponsor a native CeloHT token.

This project is an open-source, community-governed initiative built on the Celo ecosystem. It is not a token project, token sale, investment product, or blockchain protocol in its own right.

## What this means

CeloHT does not have:

- a native CeloHT token
- tokenomics for a CeloHT-issued asset
- a CeloHT token presale, ICO, or airdrop program
- token-weighted governance
- token-based fundraising or investment returns

## External assets

CELO and USDm are existing assets in the wider Celo ecosystem. They may be referenced in CeloHT materials when describing the technical and financial context for the initiative, but they are not CeloHT-issued tokens, and nothing in this project should be interpreted as a CeloHT token issuance.

## Communication rules

Any public description of CeloHT must avoid language that implies:

- token issuance
- investment return promises
- fundraising through a native asset
- governance by token holdings

When there is a question about the project's legal or financial status, the authoritative source is [LEGAL_STATUS.md](LEGAL_STATUS.md).
