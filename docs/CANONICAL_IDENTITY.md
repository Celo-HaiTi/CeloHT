# Canonical Identity

This document defines the official identity and GitHub ownership for CeloHT.

- **Official project name:** CeloHT
- **Official GitHub organization:** [Celo-HaiTi](https://github.com/Celo-HaiTi)
- **Official website:** [celoht.com](https://celoht.com)
- **Official repositories:** Official CeloHT repositories are hosted under Celo-HaiTi unless explicitly documented otherwise.

CeloHT is the project and initiative name. Celo-HaiTi is the canonical GitHub
organization name; they are distinct concepts.

Repositories using the CeloHT name outside Celo-HaiTi must not be treated as
official without explicit verification from the organization.
